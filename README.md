# Проект интернет-магазина

## Описание

Проект интернет-магазина - проект, разрабатываемый в процессе обучения по курсу "Разработчик на Python".
Это мой первый проект, который использует фреймворк Django. На данном этапе реализованы функции-контроллеры:
- **home**: выполняет GET-запрос и возвращает рендер шаблона *home.html*
- **contacts**: выполняет GET-запрос и POST-запрос. Если выполняется GET, то возвращает рендер шаблона *contacts.html*. Если POST, то возвращает HTTP ответ пользователю.

## Установка

Клонируйте репозиторий:

```
git clone git@github.com:Daniil-Tarasov/web-shop.git
```

Установите зависимости:
```
poetry install
```

## Использование

1. Откройте скопированный проект.
2. Запустите сервер с помощью команды `python manage.py runserver` или `python3 manage.py runserver`
